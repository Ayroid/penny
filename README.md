# Penny

Track today. Build tomorrow.

A personal money tracker. Income, expenses and transfers across your accounts,
with the daily, weekly and monthly picture. Everything stays on the phone.

- **Add in two taps.** A keypad, not a form — the amount builds paise-first the
  way a bank app does.
- **Accounts and transfers.** Moving cash from the bank isn't spending, and the
  month's totals know it.
- **Categories** you can rename, recolour and archive, each with its own icon.
- **Recurring rules** for rent, salary and subscriptions. They catch up when you
  next open the app.
- **Day / week / month** everywhere, with a spend heatmap and a category
  breakdown.
- **Local, quiet, no account.** No sign-in, no sync, no analytics. Your backup is
  a JSON file you export and keep.

## Build

```sh
flutter run                       # debug
flutter test                      # 161 unit, widget and golden tests
flutter test --update-goldens     # only when a pixel change is deliberate
flutter analyze
tool/release.sh                   # split-per-abi release APKs into releases/
```

## Layout

`lib/` is flat, one file per screen or sheet, plus four that cut across:

- **`store.dart`** is the model and the only thing that persists — one
  `ChangeNotifier`, one JSON blob in `shared_preferences`. Every screen listens.
- **`theme.dart`** holds the palette and every shared shape (`TintCard`,
  `Segmented`, `TintChip`, `RoundIconButton`, `CategoryAccent`). If a widget is
  used twice it moves here.
- **`analytics.dart`** and **`recurring.dart`** are the maths, kept widget-free
  so they are tested by calling them rather than by pumping a tree.
- **`money.dart`** is the only place an amount becomes a string.

## Things that are settled

**Money is an integer number of paise, never a double.** `0.1 + 0.2 != 0.3`, and
a ledger that drifts is worthless. The entry keypad appends digits to an int, so
no amount is ever parsed from a string.

**Transfers are a kind, not a category.** Without them a cash withdrawal reads
as an expense and overstates the month by exactly the amount withdrawn.

**Days are `'YYYY-MM-DD'` strings and day arithmetic goes through the `DateTime`
constructor.** A `Duration` is 24 real hours and lands on the wrong calendar day
across a DST change.

**Colours are stored as palette indexes and icons as string keys.** So the
palette can be retuned and the icon package upgraded without rewriting anyone's
data.

**`onAccent` is computed, never assumed.** White on Penny's sprout measures
2.57:1 and fails a button label; navy is 5.43. `test/palette_test.dart` asserts
it, per theme.

**The coin carries no text.** It is a fill colour only — see the note at the top
of `theme.dart` for why no ink survives on the one tone that stays far enough
from the sprout to be told apart from it in greyscale.

**Nothing scolds.** A month that ended down is ordinary. Red is reserved for
destructive confirmation, never for spending.

## Mascot

Six poses, no disappointed one. The `Penny` enum names them by the family's
pose vocabulary (`standing · focus · complete · thinking · celebrate · rest`)
and maps each to the filename on Penny's own character sheet — `Penny.rest` is
the pose the sheet calls "Save".

```
art/                      hand-made, never bundled
  character-sheet.png
  mascot-source/          the six poses at ~1250px, plus the launcher crop
assets/                   generated by tool/make_icon.py, never hand-edited
  mascot/  icon/  splash/
```

**Run `python3 tool/make_icon.py` after changing any source art.** It downscales
the poses to 512px and quantises them (900 KB → 27 KB each, 5.3 MB off the APK),
renders both launcher framings, and cuts the splash mark. Then
`dart run flutter_launcher_icons`.

Constrain **height only** — the poses do not share an aspect ratio and boxing
them square renders the wide ones short. A missing pose falls back to `default`,
and `default` falls back to `CoinMark`, a drawn coin-and-sprout that also serves
the splash and the launch frame because those have to scale and recolour in a
way a raster cannot.

## Design

`../design-system.html` is the contract, and Wick is the reference
implementation. Penny differs from it in the accent alone: sprout `#34B863`,
navy `#16295C`, cream `#FFF8F1`. See `PLAN.md` for the three places the plan was
corrected while building.
